## Overview

BetaStack is a creative portfolio web application designed for modern web presence. It delivers dynamic 3D scenes, scroll-driven interactions, and seamless client-side page transitions while maintaining responsive performance across all devices.

## Key Features

- **Interactive 3D Visuals**: Canvas elements powered by React Three Fiber and Drei.
- **Micro-Interactions**: Curated animations and physics-based transitions via GSAP and Framer Motion.
- **Modular Component Design**: Decoupled, reusable UI layout components.
- **Fast Build Times**: Hot Module Replacement (HMR) and optimized assets via Vite.
- **Responsive Layout**: Designed mobile-first using Tailwind CSS v4 utility architecture.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Anas-Kashif/BetaStack---Portfolio.git
   cd BetaStack---Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
